# Sistema de Agendamento de Eventos

Trabalho da disciplina SIN 493 - Introdução à Programação Web (UFV).

Sistema web para cadastrar eventos e agendar a participação neles.

## Tecnologias

- HTML5, CSS3, JavaScript puro e PHP puro
- Dados salvos em arquivos JSON (pasta `dados/`)

## Estrutura

```
index.php, funcoes.php
css/estilo.css
js/scripts.js
dados/usuarios.json, eventos.json, agendamentos.json
```
